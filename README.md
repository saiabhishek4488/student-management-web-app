# Student Management Web Application

## Project Overview
A Java-based web application for student management. It provides web pages for student login, registration, and student record operations.

## Technologies Used
- Java
- Java Servlets
- JSP (JavaServer Pages)
- JDBC
- MySQL
- HTML and CSS
- Apache Tomcat
- Eclipse IDE

## Features
- Student registration
- Student login
- Admin login
- View and manage student information
- Update student details
- Delete student records
- Database connectivity using JDBC

## Project Structure
- `src/main/java` - Java controllers, DAO, model and database utility classes
- `src/main/webapp` - JSP pages and web application resources
- `src/main/webapp/WEB-INF` - Web configuration and library files

## Database Setup
1. Install MySQL.
2. Create the database required by the application.
3. Configure the database URL, username and password in the database connection class.
4. Create the required tables before running the application.

Do not publish real database passwords or other secrets.

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing web project.
3. Configure the JDK and Apache Tomcat server.
4. Configure the MySQL database and credentials locally.
5. Run the project on the Tomcat server.
6. Open the application URL in your browser.
